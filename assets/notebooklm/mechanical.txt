Introduction to Uncertainty
Introduction
§ Statistics/statistical analysis is a mathematical tool for
quantitative analysis of measurement data and
extracting useful information from data.
§ Summarize the observations by estimating the
average (true mean) and the variance (uncertainty)
§ Propagate the measurement error through a
mathematical model to estimate the error in the
derived quantity
§ Explore use of Probabilistic Monte Carlo method to
calculate uncertainty
Error and Uncertainty
§ Error = Measured value – True value. It is often expressed in
percentage as: (Measured value – True value)/ True value × 100
§ Uncertainty in a stated measurement is the interval of confidence
around the measured value such that the measured value is certain
not to lie outside this stated interval.
§ Uncertainty interval is usually assigned in the following formats:
L = 1.00 ± 0.01 m or 1.00 m ± 1%. Uncertainties may also be stated
along with a probability
Types of Errors
§ We will look at Random errors only
§ Gross errors and Systematic errors
would be ignored in this example

Evaluation of the Uncertainties Using
Monte Carlo Method
§ Calculating uncertainty using propagation of error
methodology works if the 𝜕y/𝜕𝑥3 can be calculated
analytically
§ If the function dependence of 𝑦 on 𝑥3 is complex,
analytical determination of the partial derivatives
𝜕y/𝜕𝑥3 is difficult, if not impossible
§ For such cases, probabilistic calculation of uncertainty
is preferred
§ Probabilistic calculation is commonly referred to as the
Monte Carlo method
Steps Involved in Calculating Uncertainties
Using Monte Carlo Method
§ Steps involved in Monte Carlo based method for
calculating uncertainty
1) Assign a probability distribution to each input
variable (𝑥3 )
2) Generate many random values according to those
distributions
3) Calculate the output (𝑦) for each set of random
values
4) Analyze the resulting output distribution
5) Calculate its standard deviation and uncertainty
interval

Code for Calculating Uncertainty using

Code to Calculate Uncertainty using Probabilistic
Monte Carlo Method for 20% Glycerol-Water Mixture
% Octave Script: Monte Carlo Probabilistic Calculation
clear; clc;
%% 1. Define Simulation Parameters
numSamples = 10000; % Number of random trials
%% 2. Define Input Probability Distributions
% Variable water viscosity in mPa-s (A)
% Normal distribution (Mean = 0.7644, StdDev = 0.0)
mu_A = 0.7644;
sigma_A = 0.0;
A = normrnd(mu_A, sigma_A, [numSamples, 1]);
% Variable glycerol-water density in kg/m^3 (B)
% Normal distribution (Mean = 1032.0, StdDev = 11.0)
mu_B = 1024.0;
sigma_B = 16.7;
B = normrnd(mu_B, sigma_B, [numSamples, 1]);
% Variable glycerol-water time in seconds (C)
% Normal distribution (Mean = 166.0, StdDev = 1.8)
mu_C = 166.0;
sigma_C = 1.58;
C = normrnd(mu_C, sigma_C, [numSamples, 1]);
% Variable water density in kg/m^3 (D)
% Normal distribution (Mean = 1000.0, StdDev = 14.1)
mu_D = 1000.0;
sigma_D = 14.1;
D = normrnd(mu_D, sigma_D, [numSamples, 1]);
1 of 3
% Variable water time in seconds (E)
% Normal distribution (Mean = 95.6, StdDev = 1.14)
mu_E = 95.6;
sigma_E = 1.1;
E = normrnd(mu_E, sigma_E, [numSamples, 1]);
%% 3. Evaluate the Formula
% The operation is element-by-element
% using .* and ./ for arrays
Y = A .* B .* C ./ D ./ E
%% 4. Analyze Probabilistic Results
mean_Y = mean(Y);
std_Y = std(Y);
y11=prctile(Y, 2.5);
% 2.5th percentile
y22=prctile(Y, 97.5);
% 97.5th percentile
%% 6. Plot the Resulting Distribution
figure;
hist(Y, 100, 'Normalization', 'pdf', 'FaceColor', [0.2 0.6 0.8],
'EdgeColor', 'none');
grid on;
hold on;
% Add visual markers for Mean and Percentiles
xline(mean_Y, 'r--', 'LineWidth', 2, 'Label', ['Mean: '
num2str(round(mean_Y,1))]);
xline(prctile_5, 'k:', 'LineWidth', 1.5, 'Label', 'p5');
xline(prctile_95, 'k:', 'LineWidth', 1.5, 'Label', 'p95');
title('Probabilistic Distribution of Y = A * B * C / D / E');
xlabel('Output Value (Y)');
ylabel('Probability Density');
hold off;
%
% Calculate the probability that Y exceeds mean value
threshold = mean_Y;
prob_exceeds = mean(Y > threshold) * 100;
%% 5. Display Summary Statistics in Command Window
fprintf('--- Probabilistic Analysis Results ---\n');
fprintf('Expected Value (Mean) of Y: %.3f\n', mean_Y);
fprintf('Standard Deviation of Y: %.3f\n', std_Y);
fprintf('2.5 th Percentile (p2.5):
%.3f\n', y11);
fprintf('97.5 th Percentile (p97.5): %.3f\n', y22);
fprintf('Probability Y > %d:
%.2f%%\n', threshold,
prob_exceeds);
